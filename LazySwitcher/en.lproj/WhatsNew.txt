• The big one: corrections were being applied and recorded as failures.

  The text changed correctly, but internally it counted as a failure — so the
  keyboard layout was never switched. You fixed a word and carried on typing
  in the same wrong layout, and the next correction came out wrong. That was
  the "works every other time" problem.

• A word is no longer thrown away when the application has not yet said what
  the cursor is in. It waits for the answer and fires when it arrives.

  Pressing double Shift used to help — not because it woke anything up, but
  because it was the only path that asked properly. Now both do.

• Select any phrase and press double Shift to switch its layout. It works
  with commas, dashes, line breaks and emoji: one unfamiliar character used
  to cancel the whole thing. And it works as many times in a row as you like
  — a second press could previously undo the first correction instead of
  converting the new selection.

• When there is less text before the cursor than we meant to replace, the
  current word is corrected on its own instead of nothing happening.
