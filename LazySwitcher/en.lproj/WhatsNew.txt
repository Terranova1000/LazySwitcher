• Fixed: the application did nothing until you switched the language by hand.

  Your hint about the language switch was exactly right. The application
  needs a layout table — what each key produces. The system does not always
  hand that over: right after launch the request can come back empty. An
  empty table was remembered permanently, and from then on every word read
  as empty and was silently dropped. Only switching the language by hand
  cleared it — which is why that helped, and why it came back in the next
  application.

  The table is now checked before it is remembered. An empty one is not
  kept, and the next attempt builds it again.

• Layouts are re-read when you switch applications. macOS remembers a
  layout per application, and we were not asking.

• Fixed: the automatic correction sometimes did nothing for the first word,
  so you had to erase it and type it again. The application asks the system
  what kind of field the cursor is in, and the answer arrived too late.

• The application no longer falls asleep with your Mac.

• Fixed the macOS 26 problems: the menu bar icon going missing, line breaks
  being swallowed, and the application switching itself off.
