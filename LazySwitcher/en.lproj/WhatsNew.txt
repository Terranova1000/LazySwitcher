1.10.1 — fixing yesterday's 1.10.

The What's New window opened empty. The text was in the build; there was
nowhere to draw it, because the text area was created with no size and
stayed at zero. What I checked at the time was that the window opened — and
it did. The test now looks for the text itself and fails when it is invisible.

The window also no longer opens behind other applications: it is ordered in
first and the application brought forward second. It used to be the other
way round, so a windowless agent came forward before it had anything to show.

What 1.10 was about:

What's New — after every update the application tells you once what changed.
To open it again: the menu bar icon → "What's New".

The text ships inside the application rather than being fetched. It reads the
same offline and with update checking turned off — the "not a single outgoing
connection" rule still holds.

The support ask is written in full but switched off: with nowhere to send
anyone, the button would be meaningless. One line turns it on.
