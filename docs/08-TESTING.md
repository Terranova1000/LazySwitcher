# 08 — Тестирование

## 1. Что проверяется автоматически

| Компонент | Что проверяем |
|---|---|
| `HotkeyDetector` | Последовательность `(flags, keyDown, timestamp)` → ожидаемое событие. Обязательные случаи: набор «Hello» не считается двойным тапом; удержание Shift 400 мс не считается тапом; тап + другой модификатор не считается |
| `KeyMapper` | Коды клавиш → строка в обеих раскладках, включая Shift-символы и мёртвые клавиши |
| `WordBuffer` | Границы слов, все правила сброса, ёмкость, `wipe()` действительно затирает |
| `VetoGate` | Таблица из сотен строк «вход → запрещено/разрешено» |
| `Scorer` | Метрики на корпусе (см. ниже) |
| `Classifier` | Сходимость, монотонность, невозможность разрешить то, что запретил порог |
| `UndoController` | Восстановление байт-в-байт, включая регистр и знаки |

## 2. Корпус и метрики

`Tools/eval/` содержит:

```
corpus/
  ru_typed_latin.txt      русские слова, записанные латиницей  → должны заменяться
  en_typed_cyrillic.txt   английские слова на кириллице        → должны заменяться
  en_genuine.txt          настоящий английский                 → НЕ трогать
  ru_genuine.txt          настоящий русский                    → НЕ трогать
  hard/
    acronyms.txt          MySQL, ntlm, API, USB, NASA
    names.txt             Ilya, Sasha, Kirill, Moskva
    tech.txt              camelCase, snake_case, /usr/bin, user@mail.ru, 192.168.1.1
    short.txt             ok, no, is, it, не, но, на, бы
    ambiguous.txt         слова, валидные в обоих чтениях
    commands.txt          ls -la, git commit -m, rm -rf, npm install
```

Отчёт `evaluate.py` печатает по каждой группе и по каждой длине слова:

```
                    ложных    пропусков
длина 3               5.2%        6.2%
длина 4-5             0.22%       0.36%
длина 6+              0.00%       0.00%
аббревиатуры          0.00%          —
имена                 0.00%          —
техтексты             0.00%          —
команды               0.00%          —
```

**Правило приёмки:** по группам `hard/acronyms`, `hard/tech`, `hard/commands`
ложных срабатываний должно быть **ровно ноль**. Не «мало» — ноль. Это те случаи,
на которых сгорела репутация Punto.

Отчёт сохраняется в репозиторий при каждом изменении моделей или порогов, чтобы
было видно, не стало ли хуже.

## 3. Ручные сценарии

Автоматизировать перехват и замену в чужих приложениях невозможно. Эти сценарии
прогоняются руками перед каждым релизом.

### Т1. Базовая замена
1. Открыть Заметки, английская раскладка
2. Набрать `ghbdtn ,hfn` и пробел
3. **Ожидается:** «привет брат », раскладка переключилась на русскую, прозвучал щелчок

### Т2. Откат
1. После Т1 нажать двойной Shift в течение 5 секунд
2. **Ожидается:** вернулось `ghbdtn ,hfn` в точности, слово попало в счётчик отмен

### Т3. Расширение области
1. Набрать `ghbdtn rfr ltkf` целиком, не дожидаясь автозамены (в приложении с
   выключенным автоматом)
2. Двойной Shift → исправилось последнее слово
3. Двойной Shift ещё раз в течение 1.5 с → захватило два слова
4. Ещё раз → вся фраза

### Т4. Выделенный текст
1. Выделить готовую фразу мышью
2. Двойной Shift
3. **Ожидается:** конвертировалась вся выделенная фраза

### Т5. Пароль в браузере — критический
1. Открыть любую форму входа в Safari, затем то же в Chrome
2. Набрать в поле пароля `ghbdtn123`
3. **Ожидается:** ничего не произошло, иконка показывает «заблокировано» или поле
   опознано как secure. Проверить в логах, что сработал слой защиты, и какой именно

### Т6. Терминал — критический
1. Открыть Терминал, набрать `ls -la` и Enter
2. **Ожидается:** ничего не изменилось, приложение в терминале выключено
3. Включить в Терминале «Защищённый ввод» и повторить: иконка «заблокировано»

### Т7. Менеджер паролей
1. Открыть 1Password (или Bitwarden), ввести мастер-пароль
2. **Ожидается:** приложение на паузе, показывает причину в меню

### Т8. Аббревиатуры и техтекст
Набрать по очереди, каждое с пробелом:
```
MySQL  ntlm  API  camelCase  snake_case  user@mail.ru  192.168.1.1  ~/Documents
```
**Ожидается:** ни одно не изменилось

### Т9. Паника
1. Нажать левый + правый Shift
2. Набрать `ghbdtn ` — ничего не происходит, иконка приглушена
3. Нажать снова — работа возобновилась

### Т10. Живучесть
1. Оставить приложение работать
2. Закрыть крышку, подождать 10 минут, открыть
3. Заблокировать экран, разблокировать
4. Переключить пользователя туда и обратно
5. **Ожидается:** после каждого — замена по-прежнему работает

### Т11. Совместимость по приложениям
Прогнать Т1 в каждом: Safari, Chrome, Telegram, Slack, Discord, Notes, Mail,
TextEdit, Pages, Notion, Figma, Obsidian, VS Code (в поле поиска, не в редакторе).
Результат заносится в таблицу совместимости.

### Т12. Ресурсы
1. Оставить работать на сутки при обычном использовании
2. **Ожидается:** память не выросла больше чем на 10 МБ от старта, CPU в покое ~0%

### Т13. Обновление
1. Поставить предыдущую версию, выдать доступ, попользоваться
2. Поставить новую версию поверх
3. **Ожидается:** доступ сохранился, настройки и обучение на месте

### Т14. Чистая установка
1. На системе, где приложения никогда не было (или после `tccutil reset`)
2. Скачать DMG, перетащить, открыть
3. **Ожидается:** понятное объяснение предупреждения Gatekeeper, онбординг доводит
   до рабочего состояния без обращения к документации

## 5. Что логировать (и чего никогда)

**Можно:** состояния tap'а, коды ошибок AX, смены Secure Input, выбранную стратегию
замены, длину заменённого слова, метрики решения без самого текста.

**Нельзя никогда:** сам набранный текст, содержимое буфера, слова из исключений
(в логах — только хеш), названия окон.

В сборке Release уровень логирования — только ошибки. Отладочный уровень включается
галочкой в настройках и сам выключается через час.

## 6. Проверка обещаний о приватности

Это не формальность — это то, чем приложение отличается от конкурентов, и это надо
уметь показать.

- [ ] `grep -ri "URLSession\|NSURLConnection\|CFStream\|socket" LazySwitcher/` — пусто
- [ ] Запустить с Little Snitch или `lsof -i -p <pid>` — ноль соединений
- [ ] Проверить, что в Application Support нет ничего, кроме настроек, списков
      исключений и весов классификатора
- [ ] Проверить, что в `~/Library/Logs` не попадает набранный текст
