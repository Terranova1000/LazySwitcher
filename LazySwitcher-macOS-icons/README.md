# Lazy Switcher — macOS App Icon Package

Готовый комплект иконки для **Lazy Switcher** — macOS-приложения для
автоматического переключения языка при наборе текста.

## Что находится в архиве

- `Assets.xcassets/AppIcon.appiconset/` — готовый App Icon для Xcode.
- `LazySwitcher-1024.png` — мастер 1024×1024 RGBA.
- `LazySwitcher-16.png` … `LazySwitcher-1024.png` — удобные отдельные PNG.
- `README.md` — эта документация.

## Установка в Xcode

1. Откройте проект.
2. Найдите `Assets.xcassets`.
3. Скопируйте папку `AppIcon.appiconset` внутрь `Assets.xcassets`.
4. В Target → General → App Icons and Launch Screen выберите `AppIcon`.
5. Если проект использует другое имя asset-а, переименуйте папку/набор или
   выберите соответствующий App Icon в настройках Target.

В набор включены стандартные размеры macOS:

| Logical size | 1x | 2x |
|---|---:|---:|
| 16×16 | 16 | 32 |
| 32×32 | 32 | 64 |
| 128×128 | 128 | 256 |
| 256×256 | 256 | 512 |
| 512×512 | 512 | 1024 |

## Дизайн

Иконка построена вокруг трёх смысловых элементов:

- ленивец — название и характер **Lazy Switcher**;
- `A` и `Я` — текущая языковая пара English/Russian;
- яркий pink/magenta фон — узнаваемый акцент приложения.

Фон за пределами округлого квадрата прозрачный. Внешняя белая рамка
не добавляется, поэтому macOS может корректно отображать иконку на разных
фонах.

## Важное замечание

Исходник — растровая иллюстрация. PNG подготовлены с качественным
Lanczos-масштабированием. Для полноценного редактируемого vector master
потребуется отдельная SVG/PDF-перерисовка; в этот пакет намеренно не
включается искусственно трассированный SVG, чтобы не ухудшать качество.

## Рекомендация

Для приложения используйте именно `AppIcon.appiconset`, а
`LazySwitcher-1024.png` храните как мастер для будущих экспортов.
