<h1 align="center">Lazy Switcher</h1>

<p align="center">
  Замечает текст, набранный не в той раскладке, и исправляет его.<br>
  Бесплатно · Локально · Без ИИ · macOS 14+
</p>

---

Замечает текст, набранный не в той раскладке, и исправляет его.

```
ghbdtn  →  привет
руддщ   →  hello
```

Живёт в строке меню, переключает раскладку заодно с текстом и держится подальше
от полей, где ошибиться дороже, чем промолчать.

**Бесплатно. Локально. Без ИИ. Ничего из набранного не пишется на диск.**

Русский и английский интерфейс. Запускается при входе в систему, если попросить.

---

## Установка

1. Скачайте DMG со [страницы релизов](https://github.com/Terranova1000/LazySwitcher/releases/latest).
2. **Перетащите** приложение в «Программы». Именно перетащите: запуск прямо из
   образа ломает сохранение настроек — macOS монтирует его копию только для чтения.
3. Откройте. macOS скажет, что не может проверить разработчика: у программы нет
   платной подписи Apple, и не будет. Путь: **Системные настройки →
   Конфиденциальность и безопасность → пролистать вниз → «Всё равно открыть»**.

   Либо одной командой:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/Lazy Switcher.app"
   ```

4. Выдайте доступ в **Универсальном доступе**. Приложение перезапустится само —
   иначе macOS продолжит отвечать ему «доступа нет» сколько угодно долго.

Нужна macOS 14 или новее.

## Как пользоваться

Наберите слово не в той раскладке и поставьте пробел — исправится само.

**Двойной Shift** делает разное, смотря по обстановке:

| Ситуация | Что происходит |
|---|---|
| Есть выделенный текст | Переводится всё выделение целиком |
| Только что была замена | Откат, и слово запоминается как «не менять» |
| Иначе | Исправляется последнее слово |

**Левый и правый Shift вместе** — пауза.

Жест настраивается: двойной ⌥, ⌃, ⌘ или одно нажатие правого модификатора.

## Чего оно не делает

- Не трогает поля паролей.
- Не работает в терминалах, менеджерах паролей, виртуальных машинах — они в
  списке исключений, и убрать их оттуда нельзя.
- Не заменяет само слова короче пяти символов. Короткие исправляются, только
  если соседнее слово подтверждает раскладку: `xnj ltkfnm` → `что делать`.
- Не трогает адреса, почту, пути, `camelCase`, токены с цифрами и всё, что
  похоже на пароль.
- Не пишет ничего о вашем вводе на диск.
- Не ходит в сеть — кроме проверки обновлений, которую вы включаете сами.
  По умолчанию выключена; кнопка «Открыть страницу загрузок» сети не требует вовсе.

## Про пароли — честно

Соблазн написать «программа физически не может прочитать ваш пароль» велик, и
это было бы неправдой. Как на самом деле:

**Где действительно не может.** Когда macOS включает защищённый режим ввода —
окно входа, менеджер паролей, поле пароля обычного приложения — нажатия не
доходят до программы вообще. Это гарантия системы, а не наше обещание.

**Где полагается на разметку.** На сайтах macOS этот режим не включает **ни один
браузер** — проверено. Там поле пароля распознаётся по разметке доступности.
В Safari это работает. В Chrome и Firefox разметки нет вовсе, поэтому там по
умолчанию доступно только ручное исправление: программа сама туда не лезет, а
вы решаете, куда нажать.

## Проверить обещания

Они на то и обещания, чтобы их можно было проверить, а не поверить на слово.

```bash
# Единственный сетевой файл в проекте — и тот выключен по умолчанию
./scripts/audit-network.sh

# Что уедет пользователю: отладочных лесов нет, песочницы нет,
# подпись привязана к сертификату, Hardened Runtime включён
./scripts/audit-release.sh

# Живые соединения работающего приложения
lsof -i -a -p $(pgrep -f "Lazy Switcher")

# Что лежит на диске: настройки, списки исключений — и ничего больше
ls -la ~/Library/Application\ Support/Lazy\ Switcher/
```

## Как это устроено

Никаких нейросетей. Словари русского и английского в виде DAWG плюс посимвольная
модель 4-го порядка — всего 3.6 МБ, читаются одним `mmap`.

Движок работает с **кодами клавиш**, а не с буквами: в коде нет ни одной строки
вроде «й соответствует q». Таблицы берутся из самой системы, поэтому нестандартные
раскладки работают по построению.

**Замеренная точность** на 25 378 словах, отложенных при сборке моделей и в
обучении не участвовавших:

| длина слова | ложных срабатываний |
|---|---|
| 4 | 0.87 % |
| **5** | **0.00 %** |
| 6 и больше | **0.00 %** |

Отсюда и порог автозамены в пять символов — он выбран замером, а не на глаз.

Слова короче пяти символов исправляются, только если следующее слово подтверждает
раскладку: `xnj ltkfnm` становится `что делать` целиком, когда доходит очередь до
второго слова.

В покое: 8.7 МБ памяти, 0.3% одного ядра, ноль сетевых соединений.

## Сборка

```bash
./scripts/make-cert.sh          # один раз: сертификат подписи
./Tools/build-models/all.sh     # словари → модели, около 30 секунд
xcodebuild test -project LazySwitcher.xcodeproj -scheme LazySwitcher \
  -destination 'platform=macOS,arch=arm64'
./scripts/install-debug.sh      # собрать и поставить в /Applications
```

Ни одной сторонней библиотеки — только системные фреймворки Apple.
