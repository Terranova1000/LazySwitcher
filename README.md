# Lazy Switcher

Маленькое приложение для macOS, которое замечает текст, набранный не в той раскладке,
и исправляет его: `ghbdtn` → `привет`, `руддщ` → `hello`. Живёт в строке меню,
переключает раскладку заодно с текстом и держится подальше от полей, где ошибиться
дороже, чем промолчать.

**Бесплатно. Локально. Без ИИ. Без сети. Ничего не пишет на диск из того, что вы набираете.**

## Как начать работу

1. Создать у себя папку проекта, например `~/Developer/LazySwitcher`
2. Положить туда содержимое этого архива: `CLAUDE.md`, `README.md`, папку `docs/`
3. Открыть эту папку в Claude Code
4. Сказать: **«Прочитай CLAUDE.md и docs/07-ROADMAP.md, начинаем с M0»**

`CLAUDE.md` — главный файл: он задаёт правила, которые нельзя нарушать, и карту
остальной документации. Он читается первым в каждой сессии.

## Три вещи, которые важнее остального

**Ложное срабатывание дороже пропуска.** Пропуск чинится хоткеем за полсекунды.
Испорченный пароль, команда в терминале или уже отправленное сообщение — нет.
Поэтому приложение молчит везде, где не уверено.

**Пароли недоступны физически.** Когда фокус в поле пароля, macOS включает режим
защищённого ввода и перестаёт отдавать нажатия вообще всем перехватчикам в системе.
Это не наша вежливость — это устройство системы. Плюс два независимых слоя сверху.

**Ничего не сохраняется.** Набранное живёт в оперативной памяти несколько секунд и
затирается при смене фокуса, приложения, при любом хоткее и просто по таймеру.
В проекте нет кода для работы с сетью — это проверяемое утверждение, и оно должно
оставаться правдой.

## Установка (когда будет собрано)

Приложение подписано самоподписанным сертификатом, но не заверено Apple — платного
аккаунта разработчика у проекта нет. Поэтому при первом запуске macOS покажет
предупреждение.

**macOS 15 и новее** (пункт «Открыть» в контекстном меню больше не работает):

1. Перетащить приложение в «Программы»
2. Попробовать открыть — система откажет
3. Системные настройки → Конфиденциальность и безопасность → пролистать вниз →
   **«Всё равно открыть»** → подтвердить

Либо один раз в терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/Lazy Switcher.app"
```

После этого приложение откроется без диалогов.
