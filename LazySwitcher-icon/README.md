# Иконки Lazy Switcher

Стеклянный стиль: фон плитки реально преломляется внутри стрелок — это не
полупрозрачная заливка, а размытая и подсвеченная копия фона, обрезанная по форме
глифа, поверх которой лежат блики и светящаяся кромка. Поэтому на разных вариантах
цвета стекло выглядит по-разному, как и должно.

## Что где

```
AppIcon.appiconset/        ← перетащить в Assets.xcassets в Xcode
Lazy Switcher.icns         ← готовый .icns, если нужен файлом
Lazy Switcher.iconset/     ← исходный набор для iconutil
MenuBar/                   ← иконки строки меню, .imageset уже с template-режимом
png/                       ← мастер-файлы 1024×1024
svg/                       ← векторные исходники, из них всё и рендерится
variants/                  ← то же самое в цветах Ocean и Graphite
preview.png                ← общий вид
```

## Установка в Xcode

**Иконка приложения.** Удалить пустой `AppIcon` из `Assets.xcassets` и перетащить
туда папку `AppIcon.appiconset`. Xcode подхватит все десять размеров.

**Строка меню.** Перетащить три папки `.imageset` из `MenuBar/` в `Assets.xcassets`.
В `Contents.json` уже проставлено `template-rendering-intent: template` — система
сама перекрасит их в чёрный или белый под тему и под выделение меню.

```swift
let item = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
item.button?.image = NSImage(named: "MenuBarIcon")     // template подхватится сам
```

Три состояния:

| Файл | Когда |
|---|---|
| `MenuBarIcon` | работает |
| `MenuBarIconInactive` | не работает: пауза, Secure Input, приложение в исключениях |
| `MenuBarIconAlert` | не выданы разрешения |

Мигание при срабатывании замены делается в коде: `button.alphaValue` на 0.35 и
обратно за 180 мс. Отдельная картинка для этого не нужна.

## Пересобрать

```bash
python3 gen.py       # SVG из параметров: цвета, геометрия стрелок
python3 render.py    # SVG → PNG 2048 через Chromium
python3 build_assets.py
python3 make_icns.py
```

Скрипты лежат рядом с исходниками. Цвета меняются в словаре `PAL` в `gen.py`,
геометрия стрелок — в функции `arrows()`.

## Почему сделано именно так

**Отдельный рисунок для мелких размеров.** 16 и 32 пикселя берутся не из большого
файла, а из упрощённого варианта: стрелки на 7% крупнее, обводка толще, размытие
преломления почти убрано, каустика отключена. Если уменьшать большой рисунок, на
16 пикселях блики превращаются в грязь.

**Форма плитки — суперэллипс, а не скруглённый прямоугольник.** Считается по
формуле `|x/a|⁵ + |y/a|⁵ = 1`, как у системных иконок. Обычное скругление углов
рядом с системными иконками сразу читается как чужеродное.

**Перечёркнутого варианта для строки меню нет.** Он был сделан и отброшен: на
18 пикселях диагональ идёт под тем же углом, что и лучи стрелок, глиф сливается в
неразборчивое пятно. Вместо него — облегчённое начертание, оно честно читается как
«сейчас не работает», а причина всё равно написана словами в меню.
